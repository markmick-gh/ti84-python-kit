# display.py

TI-84 Plus CE Python display utility library.

This library provides simple screen formatting and paging functions
for the TI-84 Python environment (MicroPython compatible).

The goal is to make TI-84 programs more readable while avoiding
desktop Python features that are unsupported on the calculator.

---

## Installation

Send `display.py` to the calculator using TI Connect CE.

On the calculator:

1. Open the Python App
2. Verify that `display.py` appears in the file list
